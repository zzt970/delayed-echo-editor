# 延时回响 · 关卡编辑器

《延时回响》的可视化关卡编辑器：拖方块画地图、绑机关、选主题贴纸，一键把做好的关卡送进游戏试玩。

> 纯前端（原生 HTML / CSS / JavaScript），无框架、无构建、无后端，**双击 map-editor.html 即可运行**。

---

## 部署到 GitHub Pages

本仓库要上传的**只有 `map-editor.html` 一个文件**（100 KB，完全自包含，无任何外部资源）。

```bash
git init
git add map-editor.html
git commit -m "延时回响关卡编辑器"
git remote add origin https://github.com/<你的用户名>/delayed-echo-editor.git
git push -u origin main
```

然后在仓库 **Settings → Pages** 里把 Source 选成 `main` 分支 / `root`，访问：

```
https://<你的用户名>.github.io/delayed-echo-editor/
```

## 与游戏联动

编辑器与游戏是**两个独立仓库、两个独立网址**，通过浏览器 `localStorage` 通信（键 `delayed_echo_inbox`）。

### 前提：必须同一域名

`localStorage` 按「协议 + 域名 + 端口」隔离。GitHub Pages 上两个仓库都挂在 `用户名.github.io` 下，**天然同源**，所以可以正常联动。

如果你把游戏部署到了别的域名，就用下面的 **「下载 .txt」方式**手工搬运（不依赖 localStorage）。

### 用法

1. 打开编辑器 → 顶栏「**游戏页**」输入框填游戏网址，例如
   `https://<你的用户名>.github.io/delayed-echo-game/`
   （输入框内容会存在浏览器里，填一次就行；留空则只投递不自动打开）
2. 画好地图 → 顶栏「**存档位**」下拉选目标（默认「自动」= 放进游戏里第一个空格；选 ①/②/③ 则覆盖那一格）
3. 点「**发送到游戏 ▶**」→ 游戏窗口自动打开，地图自动存进「我的地图」存档位
4. 之后在游戏「选择关卡」页底部随时可以「进入 / 删除」这三格里的任意一张

> 存档在**本机本浏览器**（`localStorage`），换电脑 / 换浏览器读不到。要跨设备就把地图「下载 .txt」发给对方，让对方在游戏里「导入地图」粘一下。

### 备选：下载 .txt 手工搬运

点「**下载 .txt（复制分享）**」，得到一段地图文本，直接粘到游戏源码的 `LEVELS` 定义之前即可。这条路完全不依赖浏览器存储，最稳。

## 工具栏一览

| 按钮 | 作用 |
|---|---|
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Y` |
| 清空 | 清空当前画布 |
| 抓手 | 拖动画布（按住左键右键拖动） |
| 网格 | 显示 / 隐藏网格线 |
| 编号 | 编辑格子编号（`↑↓←→` 微调，`Shift` 加速） |
| 开关自动补平衡座 | 自动补出压力板 / 平衡座 |
| 保存 | 存到本机浏览器（关掉再打开还在） |
| 下载 .txt | 导出成文本，方便复制分享或粘进游戏 |
| 发送到游戏 | 写入收件箱并自动打开游戏（游戏端会把它存进「我的地图」三个存档位之一） |
| 存档位 | 选择发到游戏的哪一格：自动 / ① / ② / ③ |
| 游戏页 | 填游戏网址（见上） |
| 选游戏文件 | 已合并进「游戏页」输入框 |

**尺寸预设**：`24 × 12`、`40 × 30`、`100 × 100`，也可以直接填宽高。

**快捷键**：`F` 刷子 / `R` 实心 / `I` 贴纸 · 平移用 `WASD` · 导出 `Ctrl+S`
