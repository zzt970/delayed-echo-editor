# 延时回响 · 关卡编辑器

《延时回响》的可视化关卡编辑器：拖方块画地图、绑机关、选主题贴纸，一键把做好的关卡送进游戏试玩。

> 纯前端（原生 HTML / CSS / JavaScript），无框架、无构建、无后端，**双击 map-editor.html 即可运行**。

---

## 部署到 GitHub Pages

本仓库要上传的**只有 `map-editor.html` 一个文件**（100 KB，完全自包含，无任何外部资源）。

```bash
git init
git add map-editor.html
git commit -m "延时回响关卡编辑器"
git remote add origin https://github.com/<你的用户名>/delayed-echo-editor.git
git push -u origin main
```

然后在仓库 **Settings → Pages** 里把 Source 选成 `main` 分支 / `root`，访问：

```
https://<你的用户名>.github.io/delayed-echo-editor/
```

## 与游戏联动

编辑器与游戏是**两个独立仓库、两个独立网址**。过去靠 `localStorage` 通信（只在同一设备同一浏览器有效），现在改成**分享链接**：地图被压进网址的 `?m=` 里，**不要求同源、不要求同设备**，微信发过去就能玩。

### 用法

1. 画好地图 → 点「**分享 / 发送 ▶**」
   - 链接自动复制到剪贴板（微信发给自己 / 朋友，点开就自动导入）
   - 同时在本机打开游戏，直接落进「我的地图」空存档位开玩
2. 之后在游戏「选择关卡」页底部随时可以「进入 / 删除」这三格里的任意一张

**游戏页地址是内置的**：编辑器只服务这一款游戏，默认就填着
`https://zzt970.github.io/delayed-echo-game/`，打开就能用，不需要配置。
只有你自己换域名、或改了游戏源码还没部署时才需要改那个小输入框
（临时填 `../delayed-echo-game/index.html` 用本地那份；清空即恢复默认）。

> 存档在**本机本浏览器**（`localStorage`），换电脑 / 换浏览器读不到。要跨设备走下面两条路，**都发给手机也没问题**。

### 一个按钮搞定：分享 / 发送 ▶

点「**分享 / 发送 ▶**」——它同时做两件事：
   - **复制链接**：这张图被压成一条网址（地图按行游程编码，10KB 的地图 → 约 1KB），微信发给自己或朋友，**手机点开就自动导入**
   - **本机打开游戏**：链接带 `ok=1`，游戏直接落进「我的地图」空存档位开玩，不用再点确认

不用登录、不用传文件、不用管存档位（游戏自动找空位，满了去选关页删一个）。
带了大量自定义图片、链接超过 30KB 时会提示改用「备份 .txt」。

### 备选：下载 .txt 手工搬运

点「**下载 .txt（复制分享）**」，得到一段地图文本，直接粘到游戏源码的 `LEVELS` 定义之前即可。这条路完全不依赖浏览器存储，最稳。

## 工具栏一览

| 按钮 | 作用 |
|---|---|
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Y` |
| 清空 | 清空当前画布 |
| 抓手 | 拖动画布（按住左键右键拖动） |
| 网格 | 显示 / 隐藏网格线 |
| 编号 | 编辑格子编号（`↑↓←→` 微调，`Shift` 加速） |
| 开关自动补平衡座 | 自动补出压力板 / 平衡座 |
| 保存 | 存到本机浏览器（关掉再打开还在） |
| 分享 / 发送 ▶ | 复制分享链接（`?m=`）+ 本机直接打开游戏 —— 唯一的发送方式 |
| 备份 .txt | 只在链接太大或想留离线备份时才用 |
| 游戏页 | 分享链接就拼在它后面；**默认已内置填好**，一般不用动 |

**尺寸预设**：`24 × 12`、`40 × 30`、`100 × 100`，也可以直接填宽高。

**快捷键**：`F` 刷子 / `R` 实心 / `I` 贴纸 · 平移用 `WASD` · 导出 `Ctrl+S`
